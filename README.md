# 一休尼帮多（IsshoniBand）

Android 乐队排练同步播放器。每个人用自己的手机听分轨，由主机统一控制播放、暂停和节拍。

## 第一次排练

准备两台或更多 Android 手机，装好同一版本的一休尼帮多，连上同一个 Wi-Fi。每个人可以听不同的分轨，比如鼓手听带提示的版本，吉他手听自己的伴奏。

1. **导入分轨**。每个人在首页打开「本地曲库」，点「导入 MP3」，选好自己的文件。只想听节拍器的人可以跳过这一步。
2. **进入同一间房**。选一台手机当主机，点「创建排练房」。其他人点「加入排练房」，选择主机的房名。
3. **选好各自的音轨**。进房后点「选分轨」。如果大家要用同一个文件，主机先选好，其他人可以在暂停或停止时点「从主机下载分轨」。
4. **定好拍子**。主机打开「歌曲设置」，调整 BPM、每小节拍数和预备拍。例如设为 120 BPM、每小节 4 拍、预备 1 小节，从首拍起播时就会先听到四下，再进音乐。
5. **开始排练**。主机按播放，所有成员跟随同一条时间轴。暂停、停止和拖动进度也由主机控制；想单练某一段，可以暂停、拖到那一段，再按播放。

## 排练时怎么调

| 听到的情况 | 在哪里调 |
|---|---|
| 我的分轨比拍子进晚了，或抢在拍子前面 | 点「音轨对齐 → 调整」。进晚了按 `＋`，进早了按 `−`。播放中可以边听边调，合适后点「存为预设」。 |
| 节拍器速度对，但每小节第一下落错了地方 | 由主机在「歌曲设置」里调整「首拍位置」。知道歌曲第一拍在哪儿，也可以在播放到那一拍时点「听到第一拍时点这里」。 |
| 想让四拍听起来一样重 | 点 BPM 旁的「首拍重音」关掉重音。拍号仍是四拍，只影响自己；打开了节拍震动时，震动力度也会一起调平。 |
| 自己的音乐和拍声一起偏晚，尤其是换了蓝牙耳机以后 | 回到首页，打开「设备设置 → 测一下延迟」。按提示测量和精调，再把结果填入这副耳机的延迟补偿。 |
| 想把拍声调大一点，又想保持伴奏音量 | 在「本机设置」里单独调节拍器音量和增益。手机音量键控制整体音量。 |

## 搜不到房间？

先确认大家连的是同一个 Wi-Fi，让主机保持在房间里，再点「加入排练房」右上角的刷新按钮。

也可以看主机房间成员列表下方的「房间地址」。如果末尾是 `:9090`，在成员手机的「手动连接」里只填冒号前面的 IP。例如房间地址是 `192.168.1.23:9090`，就填 `192.168.1.23`。3.0.4 的手动连接固定使用 9090 端口；如果主机显示其他端口，请从自动搜索列表加入。
